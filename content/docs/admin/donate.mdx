Донат в UnicoreCMS складывается из двух разных вещей, которые часто путают.

Донат-группа — привилегия целиком: VIP, Premium, Deluxe. У неё есть игровой идентификатор, на сервере её выдаёт плагин прав, и за ней обычно тянется целый список возможностей.

Донат-право — одна возможность в розницу: полёт, набор `/kit weekly`, цветной ник. Берут те, кому не нужен весь пакет.

## Периоды

Период задаёт, на какой срок покупается привилегия. Заводить периоды надо раньше групп.

| Поле | Что это |
| --- | --- |
| Название | «Месяц», «Навсегда» |
| Время в секундах | Ноль означает бессрочно |
| Множитель цены | На сколько умножается базовая цена |

Итоговую цену определяет множитель. Базовая цена группы это цена за один период: месяц идёт с множителем 1, три месяца с 2.7 (то есть со скидкой), навсегда с 10.

Периоды общие для всех групп и прав, но каждая группа выбирает свой набор. «Навсегда» нужно не везде.

## Донат-группа

**E-Commerce → Донат → Донат-группы → Создать.**

| Поле | Зачем |
| --- | --- |
| Название, описание, иконка | Витрина |
| ID в игре | Имя группы в LuckPerms или другом плагине прав |
| Цена, скидка, свой процент оплаты бонусами | Деньги |
| Приоритет | Порядок на странице доната |
| Серверы | Где привилегия действует |
| Доступные периоды | Какие сроки можно купить |
| Инжект веб-прав | Что открывается на сайте |
| Возможности (построение блока) | Список «что входит» для витрины |
| Киты | Наборы, которые привилегия даёт в игре |

ID в игре должен совпадать с именем группы на сервере. Если в LuckPerms группа называется `vip`, то и здесь пишите `vip`, иначе игрок ничего не получит.

Возможности идут галочками на карточке привилегии: «Приватные регионы ×5», «Доступ к /fly», «Цветной ник». На логику они не влияют, зато по ним игрок и выбирает.

<Callout type="warn" title="В инжект веб-прав идут только `user.`">
В донат можно положить только права из ветки `user.`, форма проверяет это при сохранении. HD-скин продать можно, а доступ в админку не получится.
</Callout>

## Донат-право

Три типа, и они ведут себя по-разному:

| Тип | Что делает |
| --- | --- |
| Игровое | Выдаёт узел прав на сервере, например `essentials.fly` |
| Веб | Открывает возможность на сайте, из ветки `user.` |
| Кит | Даёт набор предметов |

Права тоже покупаются на период и снимаются, когда срок вышел.

## Киты привилегий

Это не те же киты, что в магазине. Кит привилегии игрок получает вместе с группой: например, стартовый комплект для VIP. Собирают его отдельно, а привязывают к группе или к отдельному праву.

## Что происходит после покупки

1. С баланса списывается цена периода.
2. Игроку записывается группа или право со сроком.
3. Веб-права начинают действовать на сайте сразу.
4. Игровая часть уезжает на сервер плагином или [через RCON](/docs/admin/issuance).

Раз в десять минут фоновая задача проверяет сроки. Истёкшие привилегии она снимает: на сайте сразу, на сервере отдельной командой.

<Callout title="Продление накапливается">
Если игрок покупает ту же группу второй раз, срок прибавляется к текущему, а не заменяет его. В командах RCON за это отвечает флаг `accumulate` в шаблонах LuckPerms. Не убирайте его, иначе покупка обнулит оставшееся время.
</Callout>

## Страницы привилегий

У каждой группы автоматически появляется своя страница на сайте с описанием, особенностями, выбором периода и сервера. Верстать ничего не надо, а вот описание и особенности заполните: пустая страница продаёт плохо.

Всё это [переводится](/docs/admin/locales), включая заголовки и тексты особенностей.
