## Стек

| Часть | На чём |
| --- | --- |
| Сервер | NestJS 11, TypeORM 0.3, Express, Socket.IO |
| Фронты | Nuxt 3, Vue 3, PrimeVue 4 |
| База | MySQL / MariaDB / PostgreSQL |
| Пакетный менеджер | pnpm 11, Node 22–24 |
| Общий пакет | TypeScript, сборка через tsup |

## `unicore-common`

Здесь живёт всё, что нужно больше чем одному приложению. Не копируется, а импортируется.

| Модуль | Что внутри |
| --- | --- |
| `envconfig` | Разбор `.env` с валидацией. Единственное место, где читаются переменные |
| `ports` | Логика выбора портов и поиска `.env` |
| `constants` | Общие константы, дефолты, ключи |
| `enums` | Права (`Permission`), события |
| `issuance` | Пресеты команд RCON, плейсхолдеры, шаблонизатор |
| `locales` | Коды языков, имена кук и заголовков |
| `permissions` | Раскрытие масок прав |
| `validation` | Свои правила class-validator |
| `sanitize` | Очистка HTML |
| `duration` | Форматирование сроков с русской плюрализацией |
| `public-config` | То из конфига, что можно отдавать в браузер |

Пакет собирается в CJS и ESM сразу: сервер работает на CommonJS, а Nuxt на модулях. Экспорты разложены по подпутям (`unicore-common/issuance`, `unicore-common/ports`), чтобы фронт не тащил в бандл серверные зависимости.

<Callout type="warn" title="Правило единственного источника">
Константу или тип, который нужен двум приложениям, кладите в `common`, а не дублируйте. Список платёжных провайдеров, набор статусов, имена кук уже лежат там. Скопированное значение обязательно разъедется, вопрос только когда.
</Callout>

## Как что запускать

```bash
pnpm run dev          # всё сразу в watch
pnpm run build        # прод-сборка всех пакетов
pnpm run build:server # только common + server
pnpm run build:client
pnpm run build:admin
pnpm run sync         # синхронизация схемы БД
pnpm run seed         # демо-данные
pnpm run lint
pnpm run format
```

Команда `pnpm run boot` делает установку, сборку сервера и синхронизацию схемы за один заход. Удобно при первом развёртывании.

<Callout title="Общий пакет собирается первым">
`dev` и `build:server` сначала собирают `unicore-common`. Если этого не сделать, TypeScript будет ругаться на несуществующие типы, ведь появляются они только после сборки.
</Callout>

## Настройки pnpm

Всё, что раньше лежало в `.npmrc` и в секции `pnpm` корневого `package.json`, теперь собрано в `pnpm-workspace.yaml`: одиннадцатая версия pnpm читает настройки только оттуда, а `.npmrc` оставила под авторизацию и реестры.

```yaml
nodeLinker: hoisted        # плоский node_modules, как раньше
engineStrict: true
strictPeerDependencies: false
autoInstallPeers: true

overrides:                 # переехали из package.json
  canvas: ^3.1.0
  fastify: ^5.8.5

allowBuilds:               # кому разрешено запускать postinstall
  bcrypt: true
  canvas: true
  esbuild: true
  '@parcel/watcher': true
  core-js: false
  es5-ext: false
  '@scarf/scarf': false
```

<Callout type="warn" title="Скрипты зависимостей не запускаются сами">
С десятой версии pnpm блокирует `postinstall` у пакетов — так угнанные npm-пакеты воруют токены. Разрешение выдаётся поимённо через `allowBuilds`. В проекте оно нужно четверым: `bcrypt` и `canvas` собирают нативные биндинги, `esbuild` и `@parcel/watcher` распаковывают бинарники. Остальным разрешение не нужно, у них в `postinstall` просьбы о донате и телеметрия.
</Callout>

Ещё одно умолчание одиннадцатой версии: пакеты моложе суток не устанавливаются (`minimumReleaseAge`). Защита от свежезалитых вредоносных релизов. Если сборка вдруг падает на `ERR_PNPM_MINIMUM_RELEASE_AGE_VIOLATION`, значит в локфайл попала вчерашняя версия — пересоберите его через `pnpm clean --lockfile` и `pnpm install`, pnpm подберёт отлежавшиеся.

## Порты

| Приложение | Порт по умолчанию | Переменная |
| --- | --- | --- |
| Сайт | 3000 | `CLIENT_PORT` |
| Админка | 4000 | `ADMIN_PORT` |
| API | 5000 | `BACKEND_PORT` |

Порт из `.env` приоритетнее переменной окружения, потому что игровые панели инжектят свой `SERVER_PORT`. Фронты стартуют через `start.mjs`, который читает порт тем же кодом, что и сервер, чтобы значение везде совпадало.
