Сервер поднимает Socket.IO на том же порту, что и HTTP. По этому каналу уходит всё, что обновляется без перезагрузки страницы: онлайн серверов, события покупок, состояние текущего пользователя.

## Подключение

<Tabs items={['Гость', 'Пользователь', 'API-ключ']}>
<Tab value="Гость">

```js
import { io } from 'socket.io-client'

const socket = io('https://api.example.com')
```

Без авторизации клиент попадает в публичную комнату и видит только общие события, то есть онлайн серверов.

</Tab>
<Tab value="Пользователь">

```js
const socket = io('https://api.example.com', {
  auth: { token: refreshToken },
})
```

Передаётся **refresh-токен**, а не access. Access протухает за минуты, и соединение пришлось бы переустанавливать постоянно.

Токен можно передать и заголовком `Authorization: Bearer <refresh>`.

</Tab>
<Tab value="API-ключ">

```js
const socket = io('https://api.example.com', {
  extraHeaders: { Authorization: 'Api-Key ваш-ключ' },
})
```

Проверяется так же, как в HTTP: и сам ключ, и IP подключения.

</Tab>
</Tabs>

<Callout title="Отказ не рвёт соединение">
Если авторизоваться не удалось, клиент не отключается, а попадает в публичную комнату. Так сайт продолжает показывать онлайн даже с протухшей сессией.
</Callout>

## Комнаты

После подключения сервер разводит клиента по комнатам, чтобы события уходили точно адресатам.

| Комната | Кто там |
| --- | --- |
| `public` | Все неавторизованные |
| `user:<uuid>` | Конкретный пользователь |
| `api-key:<секрет>` | Конкретный API-ключ |
| Каждое право пользователя | Например `kernel.connect` |

Комнаты по правам работают так: событие в комнату `kernel.connect` получают все плагины, и только они.

## События от сервера

| Событие | Кому | Полезная нагрузка |
| --- | --- | --- |
| `me` | Каждому при подключении | Текущий пользователь или `null` |
| `servers/online` | Всем | Онлайн по серверам |
| `give_group` | `kernel.connect` | Игрок купил привилегию |
| `take_group` | `kernel.connect` | Срок привилегии вышел |
| `give_permission` | `kernel.connect` | Куплено отдельное право |
| `take_permission` | `kernel.connect` | Срок права вышел |

## Запросы к серверу

```js
socket.emit('servers/online', (onlines) => {
  console.log(onlines)
})
```

Пока это единственный запрос: получить текущий онлайн, не дожидаясь очередной рассылки. Онлайн и так обновляется каждые пять секунд, так что запрос пригодится в основном при первой отрисовке.

## Смена прав на лету

Когда права API-ключа меняются в админке, все его открытые соединения принудительно разрываются. Клиент переподключится и попадёт в комнаты заново. Иначе он продолжал бы получать события по старым правам.

## Прокси

Вебсокетам нужен апгрейд соединения. В nginx:

```nginx
location / {
    proxy_pass http://127.0.0.1:5000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
}
```

Без этих строк Socket.IO свалится на long-polling, а на некоторых конфигурациях не заработает вовсе. Симптом узнаваемый: онлайн серверов не обновляется, пока не перезагрузишь страницу.
